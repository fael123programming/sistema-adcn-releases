# Sistema ADCN — instaladores

Instaladores do **Sistema ADCN**, o sistema interno da Assembleia de Deus — Ministério de Madureira — Campo de Caldas Novas para **folha de pagamento** e **acompanhamento de aconselhamento**.

Este repositório contém apenas as versões publicadas (*Releases*). O código-fonte é mantido em um repositório privado.

## Como instalar

1. Abra a [versão mais recente](https://github.com/fael123programming/sistema-adcn-releases/releases/latest).
2. Em **Assets**, baixe o arquivo **`Instalar-Sistema-ADCN-<versão>.exe`**.
3. Execute o arquivo. A instalação é para o usuário atual e não pede senha de administrador. Os atalhos são criados na área de trabalho e no menu Iniciar.

> Na primeira instalação, o Windows pode mostrar **"O Windows protegeu o computador"**, porque o instalador não tem assinatura digital paga. Clique em **Mais informações → Executar assim mesmo**.

Requisitos: Windows 10 ou 11, 64 bits.

## Atualizações

Depois de instalado, o sistema se atualiza sozinho. Ao abrir (e a cada 6 horas), ele consulta esta página, baixa a versão nova em segundo plano e pergunta se pode reiniciar. Para verificar na hora, use **Ajuda → Procurar atualizações…**.

## Privacidade

Os dados da igreja (folha de pagamento e registros de aconselhamento) ficam **somente no computador** onde o sistema está instalado, na pasta `%APPDATA%\Sistema ADCN`. Nenhum dado é enviado para cá. A única comunicação com a internet é a consulta de atualizações.

Faça cópias de segurança regularmente em **Configurações → Fazer backup…** e guarde-as em um pendrive ou disco externo.
